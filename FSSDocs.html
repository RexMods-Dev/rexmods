Overview

A fully customizable Forza Horizon 5-style speedometer for GTA V. The needle moves when you start the engine, follows your RPM smoothly, vibrates when you hit the rev limit, and shows your speed clearly.

Driving assists — like ABS, Traction Control, and Launch Control — work in the background and blink on the gauge when active. You can change all settings from the in-game menu by pressing F11.

GTA V Enhanced Compatibility

The texture files included in this mod have been updated to work with GTA V Enhanced. They work well in our tests. However, because everyone uses different mods and installs them in different orders, it might not work perfectly for everyone.

Fixing Graphics Issues
If you see missing graphics, black boxes, or other visual glitches:
  1. Close the OpenIV program completely.
  2. Restart GTA V.
  3. You might need to do this up to three times. This helps the game reload the new files correctly.

If it still doesn't work, undo the changes you made in OpenIV and use the older (Legacy) version of the mod instead.

Installation (Legacy)

  1. Install the required base mods: Script Hook V, Script Hook V .NET, and LemonUI.
    Put the file named LemonUI.SHVDN3.dll into your GTA V scripts folder.
  2. Copy FSS.dll and FSS.ini from the Forza script folder into your GTA V scripts folder.
  3. Using OpenIV, open the Legacy folder in our download. Drag and drop the ForzaSpeedometerFH5.ytd file into this path in OpenIV: 
    mods\update\update.rpf\x64\data\cdimages\scaleform_generic.rpf\
  4. Start the game and press F11 to open the mod settings.

Installation (Enhanced)

This installation is almost exactly the same as the Legacy one, but you also need to install a few extra tools to make it work with GTA V Enhanced.

  1. Install the base mods: Script Hook V, Script Hook V .NET, and LemonUI.
  2. Copy FSS.dll and FSS.ini to your GTA V scripts folder.
  3. Using OpenIV, open the Enhanced folder from our download. Drag and drop the ForzaSpeedometerFH5.ytd file into this path in OpenIV: 
    mods\update\update.rpf\x64\data\cdimages\scaleform_generic.rpf\
  4. Install the RageOpenV and DirectStorageFix mods by putting their files in your main GTA V folder.
  5. Start the game.

Updating from v1.1

  1. Delete the old FSS.dll and FSS.ini files from your scripts folder. In OpenIV, delete the old ForzaSpeedometerFH5.ytd from your scaleform_generic.rpf file.
  2. Install the new files following the installation instructions above.
  3. Start the game to finish the update.

Driving Aids

Assisted Braking System (ABS)

Helps you brake with better feedback when driving fast. Slim mode gives a little help. Aggressive mode helps you stop as fast as possible.

Launch Control (LC)

Stops your tires from spinning when you accelerate from a dead stop, helping you launch faster and smoother.

Traction Control System (TCS)

Reduces engine power when your wheels start to slip to keep you in control. Sport mode lets you slide a little bit. Aggressive mode stops you from sliding almost immediately.
