Overview

A fully customisable Forza Horizon 5-style speedometer for GTA V. The needle sweeps like an ignition check, follows RPM, wobbles at the rev limiter, and shows your speed on three clean digits.

Driving aids (ABS, Traction Control, Launch Control) work in the background and blink on the gauge. Everything can be adjusted through the in-game menu by pressing F11.

What's New in v1.2

New Features

  • Controller vibration at the redline which is adjustable or can be turned off [Experimental]
  • Gamepad menu control — open the menu with a controller [Experimental]
  • Two speed display modes: classic text or crisp texture digits (both movable and scalable)
  • Hide vanilla HUD — remove the default street/vehicle name for a clean view
  • Reload Configuration button — apply .ini changes without restarting the game
  • Improved logging with performance profiler
  • Welcome Guide — shows your keybinds and file locations the first time you use the mod, reopen it anytime from the menu

Improvements

  • Better ignition sweep
  • Smoother engine-off needle fallback
  • More layout options
  • Gear indicator no longer flickers during quick gear changes

Changed

  • Launch Control and Traction Control now share a single combined Sport/Aggressive mode setting instead of being configured separately

Stability

  • Much smoother on lower-end PCs
  • Fixed the micro-stutters that used to happen when moving sliders or changing settings rapidly

Installation

  1. Install the required tools: Script Hook V, Script Hook V .NET, and LemonUI.
    Go inside the SHVDN3 folder inside and place LemonUI.SHVDN3.dll in your scripts folder.
  2. Copy FSS.dll and FSS.ini into your GTA V scripts folder.
  3. Use OpenIV to place ForzaSpeedometerFH5.ytd inside: 
    mods\update\update.rpf\x64\data\cdimages\scaleform_generic.rpf\
  4. Launch the game and press F11.

Updating from v1.1

  1. Delete the old FSS.dll and FSS.ini from your scripts folder. Delete the old ForzaSpeedometerFH5.ytd from your scaleform_generic.rpf

  2. Copy the new FSS.dll and FSS.ini into scripts.
  3. Add the ForzaSpeedometerFH5.ytd using OpenIV (inside the scaleform_generic.rpf archive) with the new version.
  4. Launch the game.

Driving Aids

ABS — Assisted Braking System

Provides braking assistance under heavy stopping. Slim mode gives moderate stopping help. Aggressive mode provides faster, stronger stopping power.

Launch Control

Prevents wheelspin when accelerating from a stop, giving more consistent launches.

Traction Control

Cuts engine power if the wheels lose grip. Sport allows light wheelspin. Aggressive catches wheelspin instantly.

Manual Reverse

When enabled, the game will not reverse automatically. Press L to enter reverse mode manually.

INI Configuration Reference

This section documents every setting inside FSS.ini. No coding knowledge is required — open the file with Notepad, find the setting you want, and change it. You can also adjust most settings through the in-game menu (F11). Edit the .ini file only if you prefer to type exact numbers or cannot open the menu.

[Global]
SettingDefaultOptionsDescription
Enable Mod True True / False True = speedometer is on. False = everything is switched off.
EngineKey Z Any key Keyboard key that starts or stops the engine. Can be any key such as E, X, etc.
EnableManualEngineControl True True / False True = you decide when the engine is on or off using the EngineKey. False = the game handles the engine normally; the speedometer still shows RPM but you cannot turn the engine off with your key.
UseMPH False True / False False = speed shown in km/h. True = speed shown in mph.
LogLevel Info Debug / Info / Warning / Error Controls how much detail is written to scripts\FFSlog.txt. Info is recommended for normal use. See warning below.
EnablePerformanceProfiler False True / False Advanced testing only. When True, writes frame times to scripts\FSS_Profile.csv. Keep False unless you are checking performance.
Warning — LogLevel = Debug
Setting LogLevel to Debug makes the mod write every tiny action to scripts\FFSlog.txt. The file grows very quickly — after a few hours of gameplay it can reach hundreds of megabytes.

Only use Debug mode if you are trying to find a recurring bug or crash, and switch back to Info as soon as you finish. If you forget and the log becomes too large, the mod will automatically archive it to FFSlog.old, but you can also safely delete both files at any time.
[Keyboard]
SettingDefaultDescription
MenuKey F11 Key that opens the mod menu. Can be changed to any key such as F10.
EngineKey Z Key to start/stop the engine. Overrides the Global EngineKey if you want different behaviour.
[Gamepad]
SettingDefaultDescription
ModifierMenu ScriptRRight The button you hold on a controller to open the menu together with KeyMenu.
KeyMenu PhoneUp The button you press while holding the modifier to open the menu.
EnableRumble True Master switch for all gamepad vibration. False turns off all rumble.
RumbleStrength 0.5 How strong the controller vibrates. 0.0 = no vibration, 1.0 = maximum. Accepts decimals such as 0.3 or 0.8.
[Visuals]
SettingDefaultOptionsDescription
SpeedDisplayMode 0 0 / 1 0 = Classic text digits (smooth, simple). 1 = High-quality textured digits (sharper, more Forza-like).
HideVanillaVehicleInfo True True / False True hides the default vehicle name, area name, and street name from the bottom-right of the screen. False leaves the vanilla HUD visible.
[CarControl]
SettingDefaultOptionsDescription
EnableCarControl True True / False Master switch for all driving aids. True enables ABS, Traction Control, and Launch Control. False disables all of them.
AllowBurnouts True True / False True allows wheel spin when holding brake and throttle at very low speed. False prevents burnouts completely.
NeedleMotorMode 0 0 / 1 Controls how the needle moves. 0 = PMDC (Slow Fall) — needle drops gently, like an older car. 1 = Stepper (Precise) — needle tracks RPM more sharply.
ABSEnabled True True / False Turns ABS on or off. Only active when EnableCarControl is True.
ABSMode 0 0 / 1 0 = Slim — moderate stopping help. 1 = Aggressive — faster, stronger stopping power.
LCEnabled True True / False Turns Launch Control on or off.
TCSEnabled True True / False Turns Traction Control on or off.
TCSMode 0 0 / 1 0 = Sport — allows a little wheelspin. 1 = Aggressive — catches wheelspin quickly.
ManualReverseEnabled True True / False True = the game does not automatically reverse; press the Reverse key to enter reverse mode. False = the game controls reverse normally.
KeyToggleABS NumPad3 Any key Keyboard key to toggle ABS on or off.
KeyToggleLC NumPad1 Any key Keyboard key to toggle Launch Control on or off.
KeyToggleTCS NumPad2 Any key Keyboard key to toggle Traction Control on or off.
KeyToggleReverse L Any key Keyboard key to toggle manual reverse mode.
[FH5] — Layout & Position Settings

Everything in this section controls where each part of the speedometer appears on screen and how large it is. All values can be adjusted through the in-game menu (F11 → FH5 Theme submenu). Only edit these manually if you need to enter exact coordinates.

SettingDescription
Global_Scale Scales the entire speedometer uniformly. 1.0 = normal size, 1.5 = 50% larger.
Global_OffsetX Moves the entire speedometer left or right.
Global_OffsetY Moves the entire speedometer up or down.
Gauge_X / Gauge_Y Position of the main gauge disc on screen.
Gauge_Size Size of the main gauge disc.
Speed_X / Speed_Y Position of the speed digits in classic text mode.
Speed_Scale Size of the speed digits in classic text mode.
TexSpeed_X / TexSpeed_Y Position of the speed digits in texture mode.
TexSpeed_Scale Size of the speed digits in texture mode.
Needle_StartAngle Angle at which the needle rests when at zero RPM.
WobbleAmp Amplitude of the needle wobble at the rev limiter.
All remaining values in the [FH5] section control the look and feel of the gauge. The easiest way to explore them is through the in-game menu.
